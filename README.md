# Olá, eu sou Tymotheo Trisch 👋

Sou desenvolvedor full stack, com formação técnica em Desenvolvimento de Sistemas pelo Senac. Meu foco é criar aplicações web, APIs e integrações que resolvem problemas do dia a dia.

Também trabalho com automação em PowerShell e diagnóstico de serviços em ambientes Windows. Gosto de acompanhar o que acontece depois que uma aplicação entra em operação, da análise de logs à validação de backups e à recuperação de serviços.

## Projetos em destaque

- **[Calendar Integration Service](https://github.com/TymotheoTrisch/microservico_calendar)** — Microserviço de integração com o Microsoft Graph, com processamento assíncrono de eventos, auditoria e painel administrativo em React.
- **[JEBusiness](https://github.com/TymotheoTrisch/JEBusiness)** — Aplicação web para gerenciar produtos, estoque e vendas, com relatórios para pequenos negócios.
- **[Sportchê](https://github.com/TymotheoTrisch/sportche-pi)** — Projeto de conclusão do curso técnico. A aplicação ajuda quem pratica esportes a organizar partidas e encontrar pessoas para jogar.

## Tecnologias

- **Backend e integrações** — PHP, Laravel, Node.js, Express e Microsoft Graph
- **Frontend** — React, TypeScript e JavaScript
- **Dados e operação** — PostgreSQL, MySQL, Redis, Docker e PowerShell
